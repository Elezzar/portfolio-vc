# Портфолио Никиты Ворожищева

[Открыть портфолио](https://elezzar.github.io/portfolio-vc/)

Двуязычное портфолио фронтенд-разработчика. В разделе «Мои проекты» собраны кейсы с описаниями, технологиями, галереями скриншотов и ссылками на исходный код.

## Технологии

React, TypeScript, Vite, SCSS и БЭМ. Для автоматических тестов используются Vitest и React Testing Library.

## Локальный запуск

```bash
npm ci
npm run dev
```

Открой адрес, который Vite выведет в терминале рядом с `Local`.

## Проверки

- `npm test` — запустить тесты.
- `npm run test:coverage` — получить отчёт о покрытии.
- `npm run typecheck` — проверить типы.
- `npm run build` — проверить типы и собрать сайт в `dist/`.

## Каталог проектов

Описания на двух языках, технологии и ссылки на GitHub хранятся в `src/data/projects.json`. Скриншоты лежат в `src/assets/projects/<id>/`. Первый кадр в записи проекта используется как обложка карточки.
